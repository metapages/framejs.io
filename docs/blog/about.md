## framejs.io: open web artifacts, owned by whoever holds the link

Generate and run self-contained JavaScript iframes (metaframes) using AI — from chat interfaces or directly from the Command Line Interface, or via APIs.

The familiar reference point is the artifact an AI assistant builds for you inside the chat. This is the same unit of work with the platform removed from underneath it: the artifact is a URL, so it runs, embeds, and is edited outside the app that made it.

The pages are embeddable, editable, customizable chunks of javascript code. 

Standalone, or as input / output pipes. 

They are the ideal composable unit for dashboards, editable or highly user customizable websites, scientific notebook components, interactive figures, and complete mini websites. 

They are publicly addressable, when wanted: immutable, and Open Graph accessible. 

They give the user control and increased safety: limited blast radius, and no hidden state — rather, complete visibility.
